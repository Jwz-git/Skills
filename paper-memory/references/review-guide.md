# 主动回忆复习指南

执行 `review` 模式时使用本文档。核心规则：**绝不先展示论文摘要或答案**，必须通过主动回忆对话引导用户。以下问题以计算论文为例；其他论文按 [paper-types.md](paper-types.md) 替换问题语义，阶段和评分结构保持不变。

## 0. 复习前准备

1. **定位 Memory**：按 profile 在 Memory 根目录、Notion database 或等价容器中查找对应笔记，读取后作为提问、反馈和评分的依据。
2. **找不到笔记时**：告知用户尚未找到该论文的 Memory，建议先用 `compress` 模式创建，不凭空出题。
3. **读取复习历史**：按 `review.persistence` 读取——`body` 读笔记中的「复习记录」，`metadata` 读已配置的复习字段，`external` 读 `review.location` 中该论文的记录，`none` 不读取。不要假定 frontmatter 一定含有复习字段。

## 1. 四阶段复习流程

按以下四个阶段逐步提问，每次只问一个阶段，用户回答并收到反馈后再进入下一阶段：

```text
阶段一：自由回忆 → 阶段二：结构回忆 → 阶段三：机制与证据 → 阶段四：批判与迁移
```

### 阶段一：自由回忆
> 请不用看笔记，用一句话说明这篇论文解决什么问题，以及核心方法是什么。

### 阶段二：结构回忆
针对论文的方法或论证结构提问，例如：
- 模型的输入和输出分别是什么？训练阶段和推理阶段有何不同？
- 使用了哪些编码器或骨干网络？各模态在哪里、如何交互或对齐？
- 损失函数是什么？推理阶段如何工作（如零样本预测流程）？

### 阶段三：机制与证据
- 作者为什么选择这种设计，而不是其他替代方案？
- 模块 X 具体解决什么问题？去掉它会怎样？
- 主要结论由哪些实验或证据支持？比较对象和设置是什么？
- 这种方法依赖哪些隐含或未说明的假设？

### 阶段四：批判与迁移
- 这种方法能否迁移到你当前的研究课题？如何迁移？
- 哪些组件可以直接复用，哪些必须修改？
- 你会设计什么实验来验证这种迁移？

## 2. 反馈格式

用户回答每个阶段后，先给出反馈再进入下一阶段：

```text
掌握正确：[用户回答正确的内容]
遗漏内容：[用户遗漏的关键细节]
存在混淆：[用户表述中的误解或错误事实]
建议复习：[建议复习的笔记具体章节]
下一题：[下一阶段的问题]
```

## 3. 评分（10 分制）

会话结束时按维度给出整数分，每个维度 0、1 或 2 分：

- `0`：无法回忆，或存在改变结论的关键错误。
- `1`：主线正确，但遗漏关键细节或条件。
- `2`：完整、准确。

| 维度 | 考查内容 |
| --- | --- |
| 研究问题 | 论文的目标问题和以往方法的局限 |
| 核心思想 | 核心创新和洞察 |
| 方法流程 | 输入输出、结构和训练目标 |
| 实验理解 | 支撑结论的实验、比较对象和设置，以及结论的边界 |
| 批判与迁移 | 局限分析、迁移到自身课题和设计验证实验的能力 |

某个维度在会话中没有被问到时，先补问再评分，不凭印象打分。只给出各维度分数和总分，不另加未定义的等级评语。

评分卡格式：

```markdown
## 复习得分总结

| 维度 | 得分 | 表现分析 |
| --- | --- | --- |
| 研究问题 | /2 | |
| 核心思想 | /2 | |
| 方法流程 | /2 | |
| 实验理解 | /2 | |
| 批判与迁移 | /2 | |
| **总分** | **/10** | |

**薄弱点记录**：
- [用户困难的具体组件或模块]
- [后续建议，如“重新阅读 CLIP 的分布偏移实验”]
```

## 4. 复习记录持久化

只有本次任务获得写入授权时才持久化；否则只在会话中输出评分卡。为保持精读笔记正文纯净，推荐配置 `none`（仅对话反馈）或 `external`（独立复习记录文件）。按 `review.persistence`：

- `none`：只在会话中输出。
- `body`：在笔记末尾的 `## 复习记录` 章节追加一条记录（日期、各维度得分、总分、薄弱点）；章节不存在时创建在笔记末尾，每条记录用 `### YYYY-MM-DD 复习`。
- `metadata`：只更新 `metadata.fields` 中已配置或笔记中已存在的复习字段（如上次复习日期、复习次数），沿用原字段名；没有对应字段时询问用户，不自行新建。
- `external`：在 `review.location` 下按 [templates/review-session.md](../templates/review-session.md) 新建记录，命名为 `<笔记名>-复习-YYYY-MM-DD`；同名记录已存在时追加序号，不覆盖。
