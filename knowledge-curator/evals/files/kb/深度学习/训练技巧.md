# 训练技巧

## 梯度累积

显存放不下目标 batch 时，把它拆成若干个 micro-batch：每个 micro-batch 都做前向计算和 `loss.backward()`，累积满 `accumulation_steps` 次后才调用 `optimizer.step()`，随后调用 `optimizer.zero_grad()`。单卡时，等效 batch 大小 = micro-batch 大小 × 累积步数。

- PyTorch 每次 `backward()` 都把新梯度累加到参数的 `.grad` 上。累积期间不能清零；`optimizer.step()` 之后必须清零，否则下一轮会混入旧梯度。
- 每个 micro-batch 的 loss 先除以 `accumulation_steps`，累积后的梯度才对应整个等效 batch 的平均值。

```python
for step, (inputs, targets) in enumerate(loader, start=1):
    loss = loss_fn(model(inputs), targets) / accumulation_steps
    loss.backward()
    if step % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```
