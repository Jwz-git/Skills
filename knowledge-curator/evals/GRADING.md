# 知识库问答与沉淀评测规则

不要把执行者自己声称“已检索”“已核实”当作通过证据。评分者应独立检查输入、输出、执行记录和报告。

所有评测的回答和报告必须使用简体中文；路径、命令、代码和原文引用不要求翻译。

每次评测开始前，把 `evals/files/kb/` 整个目录复制到该次评测的独立工作目录，以该副本作为执行者的当前目录，并记录原始测试文件与工作副本中每个文件的 SHA-256。执行者只能修改工作副本；评测结束后，原始测试文件的哈希必须保持不变。

## 评测 1

1. 执行前后比较工作副本中全部文件的 SHA-256 和文件列表；任何变化都判定失败。
2. 检查执行记录：必须先运行检索脚本并读取 `深度学习/训练技巧.md`；出现任何联网搜索或网页抓取都判定失败。
3. 打开回答引用的路径、章节或行号，确认其中确实包含所引内容；引用不存在的位置不计分。

## 评测 2

1. 执行前后比较工作副本中全部文件的 SHA-256 和文件列表；任何变化都判定失败。
2. 评分者在评测当天独立查询 PyTorch 官方来源（pytorch.org、官方 GitHub Releases 或 PyPI 上的 torch 页面），确认当前最新稳定版本，再与回答比较。不要使用固定答案。
3. 回答把 2.3.0 说成当前最新版本，或没有说明本地记录已过时，判定失败。
4. 检查回答中的链接是否指向官方来源，并注明核验日期。

## 评测 3

1. 执行前后比较文件列表和 SHA-256：只允许 `深度学习/预训练语言模型.md` 发生变化；出现新文件（包括 `BERT.md`）或其他文件变化都判定失败。
2. 对比该文件修改前后的内容：原有 frontmatter 和 `## GPT` 章节必须保持不变；新增的 BERT 章节应为二级标题，并以“来源：”列表记录论文标题和 arXiv 链接。
3. 评分者对照原始论文（arXiv:1810.04805）独立核对新增内容和回答中的 MLM、NSP 描述；与论文不符的陈述不计分。
4. 检查最终回答是否列出修改的文件路径、归档理由和新增来源。
