# Paper Tutor 输出格式示范

本文件提供三种典型场景的输出骨架，供执行 `paper-tutor` 时对齐节奏与细节颗粒度。

---

## 示例 1：模式 A 第 1 轮（论文概览 + 核心术语 + 推进目录 + Abstract）

```markdown
# 《论文标题》逐段精讲

## 一、论文概览

- **一句话核心**：本文提出 XXX，用于解决 YYY 问题……
- **所解决的问题**：现有方法在……场景下存在 A、B 两个瓶颈……
- **提出的方案**：整体采用两阶段设计……直观上就像……
- **取得的结果**：在基准数据集 D 上，核心指标提升了 X%……
- **局限与改进空间**：
  - *论文自述局限*：作者指出当前方法在……条件下性能会下降，未来可探索……
  - *延伸思考*：从工程落地看，……部分对算力/数据标注的依赖可能成为瓶颈。

## 二、核心术语速览

- **粗到精定位（Coarse-to-Fine Localization）**：先在大地图里快速圈出大概街区（粗定位），再在街区里精确算出具体坐标（精定位）。
- **对比学习（Contrastive Learning）**：把“配对的图文”拉近、把“不配对的图文”推远的训练思路。

## 三、全文分节推进目录

- [x] **第 1 轮**：论文概览 + Abstract（本轮）
- [ ] **第 2 轮**：`§1 Introduction`（约 5 段 + Fig. 1）
- [ ] **第 3 轮**：`§2 Related Work`（约 4 段）
- [ ] **第 4 轮**：`§3.1 Global Place Recognition`（原 §3 较长，按二级小节拆讲 + Fig. 2 + 公式 (1)–(3)）
- [ ] **第 5 轮**：`§3.2 Fine Localization`（+ Fig. 3 + 公式 (4)–(6)）
- [ ] ……
- *附录清单（正文结束后按需精讲）*：Appendix A（实现细节）、Appendix B（更多可视化）

---

## 四、Abstract 逐段精讲

#### [Abstract 第 1 段] *"We tackle the problem of..."*

**译文**：我们针对……问题，提出了一种新的神经网络……

**讲解**：摘要按经典“问题 → 方案 → 亮点 → 结果”四步展开。……举个具体例子：……

---
> **当前进度**：已完成「论文概览 + Abstract」。  
> 回复 **“继续”** 进入下一节 `§1 Introduction`，或随时对以上任何内容提问。
```

## 示例 2：模式 A / B 含公式、就地穿插图表、表格与伪代码的正文片段

```markdown
## §3.1 缩放点积注意力（Scaled Dot-Product Attention）

#### [§3.1 第 1 段] *"We call our particular attention..."*

**译文**：我们将这种特定的注意力称为“缩放点积注意力”（如图 2 左所示）。输入由维度为 $d_k$ 的查询和键以及维度为 $d_v$ 的值组成……

**讲解**：这一段把核心算子的输入接口讲清楚了。可以把 `Query`、`Key`、`Value` 想象成查资料：……

> **图表解读｜Figure 2（左）：Scaled Dot-Product Attention**（随第 1 段首次引用就地讲解）
> - **图注译文**：（左）缩放点积注意力……
> - **图面拆解**：从下往上数据依次经过 `MatMul`（计算 Q 和 K 的相似度）→ `Scale`（除以 $\sqrt{d_k}$ 防止数值爆炸）→ `Mask (opt.)`（解码器用来遮住未来词）→ `SoftMax`（转成加权概率）→ `MatMul`（对 V 加权求和）。

#### [§3.1 第 2 段] *"In practice, we compute the attention..."*

**译文**：在实际实现中，我们将一组查询打包成矩阵 $Q$ 同时计算注意力函数……

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

- **一句话直觉**：先算每个查询和所有键的匹配分数，缩小一下防止梯度消失，归一化成权重后，对所有值做加权平均。
- **逐符号拆解**：
  - $Q \in \mathbb{R}^{n \times d_k}$：查询矩阵，$n$ 是查询数量，$d_k$ 是每个查询向量的维度；
  - $K \in \mathbb{R}^{m \times d_k}$：键矩阵，$m$ 是键/值对数量，$K^\top$ 表示转置，使 $QK^\top$ 得到 $n \times m$ 的两两相似度矩阵；
  - $\sqrt{d_k}$：缩放因子，防止维度 $d_k$ 很大时点积结果过大，导致 softmax 梯度趋近于 0；
  - $\mathrm{softmax}(\cdot)$：按行归一化，让每一行权重之和等于 1；
  - $V \in \mathbb{R}^{m \times d_v}$：值矩阵，最终输出维度为 $n \times d_v$。
- **极简数值例子**：假设 $d_k = 4$（所以 $\sqrt{d_k} = 2$），一个查询 $q = [2, 0, 2, 0]$，两个键 $k_1 = [2, 0, 0, 0]$、$k_2 = [0, 0, 0, 2]$……

#### [§3.1 第 3 段] *"Next, we introduce the multi-head..."*

**译文**：接下来，我们介绍多头注意力机制。

**讲解**：短过渡段，承接上文的单头注意力，引出下一节“并行用多个头从不同子空间看关系”的设计。

> **表格解读｜Table 1：不同层类型的复杂度对比**（随引用段就地讲解）
> - **核心总结**：比较自注意力、循环层（RNN）、卷积层（CNN）在计算量、顺序操作数和最大路径长度上的权衡。
> - **看表重点**：三项指标均为**越低越好（↓）**；基准是 RNN 和 CNN；自注意力的最大亮点在于顺序操作数和任意两词路径长度都是 $O(1)$（极利并行且易抓长距离依赖），短板是当序列长度 $n$ 远大于维度 $d$ 时，每层复杂度 $O(n^2 \cdot d)$ 会高于 RNN。

> **算法伪代码｜Algorithm 1：核心推理流程**
> ```text
> Input: query Q, key K, value V
> 1. S <- (Q @ K^T) / sqrt(d_k)
> 2. W <- softmax(S, dim=-1)
> 3. Output <- W @ V
> ```
> - **分步拆解**：第 1 步算缩放相似度矩阵；第 2 步按行归一化为注意力权重；第 3 步按权重汇聚值向量。
```

## 示例 3：模式 C（英文选段精读）

> 当用户粘贴多段英文时，按如下结构**逐段输出，不合并段落**。

```markdown
### 第 1 段

**原文**：
> While this results in better global descriptors, both approaches match global descriptors using the pairwise ranking loss without considering the imbalance in positive and negative samples.

**译文**：
尽管这带来了更好的全局描述符（Global Descriptor），但这两种方法都使用成对排序损失（Pairwise Ranking Loss）来匹配全局描述符，却没有考虑正负样本之间的不平衡问题。

**讲解**：
- **核心意思**：作者在“先扬后抑”——先承认前人工作（RET）提升了特征表达，再点出它们共同的训练缺陷：只看一对正负样本做排序，忽略了实际地图里“错误位置（负样本）”远远多于“正确位置（正样本）”的现实。
- **举例理解**：就像在一万张人脸里找你的朋友（1 个正样本、9999 个负样本），如果每次只随机抽 1 个路人对比，模型很难学会把所有长得像的困难路人都排掉；这也是后文作者引入对比学习（Contrastive Learning）的原因。
```
